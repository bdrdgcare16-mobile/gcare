## 🔧 **TROUBLESHOOTING**

### **Common Issues**

#### **1. Login Problems**
- **Issue:** Can't login
- **Solution:** Check email/password, try default credentials
- **Default:** Employee@123 / Admin@123

#### **2. Profile Not Loading**
- **Issue:** Profile shows old data
- **Solution:** Refresh page, check internet connection
- **Alternative:** Use session data

#### **3. Camera Not Working**
- **Issue:** Camera check-in fails
- **Solution:** Allow camera permissions, try manual entry
- **Alternative:** Use desktop camera screen

#### **4. Tasks Not Visible**
- **Issue:** Tasks don't appear
- **Solution:** Check backend connection, refresh page
- **Alternative:** Contact admin

#### **5. Attendance Issues**
- **Issue:** Can't mark attendance
- **Solution:** Check location, try different method
- **Alternative:** Contact admin for manual entry
