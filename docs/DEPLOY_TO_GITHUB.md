# 🚀 DEPLOY TO GITHUB PAGES - FREE WEB HOSTING

## ✅ **STEP 1: Create GitHub Repository**

1. **Go to GitHub.com** and sign in
2. **Click "New repository"**
3. **Name it:** `nishali-hrms-app`
4. **Make it Public** (required for free hosting)
5. **Click "Create repository"**

## ✅ **STEP 2: Upload Your Web App**

### **Method A: Using GitHub Desktop (Easiest)**
1. **Download GitHub Desktop**
2. **Clone your repository**
3. **Copy all files from `build/web/` to the repository**
4. **Commit and push**

### **Method B: Using Git Commands**
```bash
cd build/web
git init
git add .
git commit -m "Initial commit - HRMS App"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/nishali-hrms-app.git
git push -u origin main
```

## ✅ **STEP 3: Enable GitHub Pages**

1. **Go to your repository on GitHub**
2. **Click "Settings"**
3. **Scroll to "Pages" section**
4. **Source: Deploy from a branch**
5. **Branch: main**
6. **Folder: / (root)**
7. **Click "Save"**

## ✅ **STEP 4: Your App is Live!**

Your app will be available at:
```
https://YOUR_USERNAME.github.io/nishali-hrms-app/
```
