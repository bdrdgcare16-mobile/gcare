# Face Recognition App

A professional Flutter application with real-time face recognition capabilities, built for mobile and web platforms.

## 🚀 Features

### ✅ Core Functionality
- **User Authentication System** - Secure login interface
- **Face Registration** - Capture and store face biometrics
- **Face Verification** - Real-time face matching
- **Camera Integration** - Professional camera interface
- **Cross-Platform** - Works on Android, iOS, and Web

### ✅ Technical Features
- **Real Camera Access** - Uses device camera hardware
- **Permission Handling** - Proper camera permissions
- **Professional UI** - Modern, responsive design
- **Error Handling** - Robust error management
- **State Management** - Efficient app state handling

## 🛠️ Technology Stack

- **Framework:** Flutter 3.x
- **Language:** Dart
- **Camera:** image_picker package
- **Storage:** SharedPreferences
- **UI:** Material Design 3
- **Platforms:** Android, iOS, Web

## 🚀 How to Run

### Prerequisites
- Flutter SDK (latest version)
- Android Studio / VS Code
- Android/iOS device or emulator

### Installation Steps
1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/face-recognition-app.git
   cd face-recognition-app
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Run the app**
   ```bash
   flutter run
   ```

### For Mobile (Recommended)
```bash
flutter run --release
```

### For Web
```bash
flutter run -d chrome
```
